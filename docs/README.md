# kiwi-template documentation

kiwi-template is the starting point for a Kiwi Network desktop app and the
home of the code all Kiwi apps share. Two words to know: the **kit** is that
shared code, a folder that is the same in every app; the **example app** is
the small notes app around it, which you replace with your own.

| Page | For | What it covers |
|---|---|---|
| [Starting an app](new-app.md) | app authors | from the template to your own app |
| [Layout](layout.md) | app authors | every folder and file, and what belongs where |
| [The kit](kit.md) | app authors | each shared module and how to use it |
| [UI rules](ui-rules.md) | app authors, designers | what every Kiwi app does the same way |
| [Development](development.md) | contributors | tests, CI, versions, releases |

These pages are also on [kiwi-network.eu](https://kiwi-network.eu/docs/),
where they are pulled from this folder at every release.
